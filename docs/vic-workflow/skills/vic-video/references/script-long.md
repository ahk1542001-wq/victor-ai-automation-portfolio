# Long script pattern

Use a longer treatment when several connected questions must be answered or a meaningful workflow needs depth. Long means explanatory depth, not a compulsory minimum number of minutes. Keep the opening concrete: what this helps the viewer do, who it fits and the outcome they will understand.

A useful arc is: task/payoff hook → plain mental model and prerequisites → connected chapters showing the mechanism → a worked input/agent/tool/preview/output journey → a boundary or counterexample that changes a real decision → trade-offs/human checks → concise synthesis and next action. Adapt the order to the subject; this is not a required chapter list.

Give each chapter one question, a visible answer and a reason to continue. Use a through-line example to preserve continuity; add another only when it reveals a different failure/decision, not to fill time. Recap a difficult dependency briefly before building on it. Do not restart the whole introduction or repeat the same benefit in every chapter.

Explain new terms at the moment they become necessary. Show who supplies data/permission, what the agent plans or drafts, what the tool actually executes, what changes in the result and where a person checks it. Do not invent an integration or imply that autonomous approval/undo/security is built into every agent. Official facts, actual execution and conceptual illustrations remain distinct.

Plan a chapter's attention changes with actions, cutaways, evidence, detail views and readable holds. New chapters need new information/visual purpose, not a reworded paragraph on the same card. Natural narration and comprehension determine length; pauses need not match a fixed global budget. Owner-approved narration remains frozen while display-only edits preserve speech.

Main resolves scope and sources before delegating execution. Inspect promise/payoff across the whole outline, redundant chapters, missing preparation, unsupported claims and the ending's practical usefulness. Apply the selected style's renderer/layout reference after the script is sound.
