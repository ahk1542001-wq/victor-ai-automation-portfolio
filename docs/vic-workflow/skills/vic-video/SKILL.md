# VIC video — one entry, five styles

Public instruction edition. Runtime implementations, personal assets and private voice driver are not bundled. Read [runtime mapping](references/runtime-map.md) before execution. Resolve local capabilities and paths; this package alone is not a turnkey renderer. It is not installed or activated by this export.

For skill-only work, edit the named instructions/resources and validate offline. Do not choose a topic, upload private data, generate speech/art or render merely to demonstrate a skill edit. An actual video request follows the production gates below.

These are five styles inside this skill, not five persistent bots. Preserve the owner's style choice; use legacy names only to recognise intent, display VIC names. Short/long labels are editorial defaults, not hard minute limits. Aspect ratio/duration can be explicitly requested; verify the chosen runtime's composition rather than silently resizing. When style is unspecified, propose the best fit with the brief; ask only if an ambiguity materially changes the work. Do not load all five runtime manuals. UI Motion and Visual Story can be combined when useful; crossing other runtimes needs an explicit plan, not mixed coordinate systems.

Load [shared research/script](references/script-core.md), then [short](references/script-short.md) or [long](references/script-long.md). Explain purpose/audience/useful outcome before jargon; focus agent+tool use on a beginner's concrete task. GitHub identity/license/dated updates support that story, not a feature-list biography. Main owns synthesis, script/storyboard, visual metaphors, pacing, sound and final review; execution workers collect specified evidence or implement complete bounded packets. Follow [production flow](references/production-flow.md); no named-bot messaging dependency or automatic fan-out.

## Produce an authorised video

1. Freeze the current brief, sources, narration/storyboard and selected style. Distinguish official evidence, observed execution and conceptual illustrations. Avoid invented guarantees, cutoff dates or verification seals. Get script/storyboard approval before new speech.
2. For every style use the canonical [shared VIC Voice procedure](../../docs/voice-and-colab.md). Preserve the saved owner reference and Voice-bot-tested pronunciation/chunking/recipe. Use its existing shared driver and actual job's upload/setup authorisation; never rewrite a second driver, retrain voice, switch TTS or use the Mac GPU. Standalone Voice remains available. A background-music choice does not change dry narration or chunk timing.
3. Bind measured speech, assets and timings through the selected runtime. Choose a fresh cast, setting, evidence, palette, actions and sound for the topic; accepted examples are mechanics references. Plan entrance→meaningful action→visible result→hold/exit. Keep text concise, shaped and clear of the selected presenter/caption zones. Do not inherit a vertical avatar/layout into a horizontal style.
4. Compose voice-first sound with topic-appropriate low-distraction backing and selective event cues. Do not default to repetitive bell/mallet/pluck loops or an effect on every popup. Honour explicit voice-only/silence choices. Keep separate dry voice/music/effects, calibrate once and report actual listening coverage.
5. For production, make a representative real-audio proof including a mechanism/result and seam. Exact proof acceptance precedes full export. Main inspects actual encoded motion, facts, typography, repetition, identity/contact, cuts and audio; worker ACK/bounds/export PASS is not creative acceptance. Preserve frozen builds; resume only verified process/checkpoint state. No retry loop or silent provider change.
6. Deliver local candidate/receipt with hashes/specs, checks and limitations. Owner accepts final; publication is separately authorised. Skill validation/native catalog discovery do not prove new-topic end-to-end production or complete listening.

Runtime roots, old proven fixtures and specific caption/presenter geometry live only in the selected style reference. Built-in tools, Voice/Job Scout profiles, models, credentials and unrelated media remain outside this consolidation.
